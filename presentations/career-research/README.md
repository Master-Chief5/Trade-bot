# Career Research deck (U1-1)

Visual redesign of the "Nathaniel Hatendi - U1-1-Career" Google Slides deck. Wording is
unchanged from the original; only layout, colour, icons and backgrounds are new.

- `Career-Research.pptx` – the deck (open in PowerPoint, or upload to Google Slides)
- `Career-Research.pdf` – rendered preview
- `deck.js` / `assets.js` – pptxgenjs generator and background/icon builder
- `links.json` – the original hyperlink targets carried over from the source deck

Rebuild:

```bash
npm install pptxgenjs react-icons react react-dom sharp
node deck.js
```
